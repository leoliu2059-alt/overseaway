## 香港办理银行卡流程

- 详情：作者线上预约办理了天星银行、中银香港（BOCHK）、众安（ZA BANK）、汇丰四家港卡。出发前需准备港澳通行证及签注、支付宝境外流量包、提前开通运营商国际漫游（否则收不到短信验证码）、下载好对应银行 APP。高铁到九龙站后建议直接打开手机漫游用流量卡上网，不要连仅 30 分钟的免费 WIFI（断网会导致办卡重头再来）。在"移民局 12367"小程序出具出入境记录后，即可在 APP 内按步骤填信息办卡，核心资料就是 12367 出入境记录。注意事项：①网络必须全程稳定；②牢记用户名密码（有朋友忘用户名跑了 3 趟）；③务必提前开通国际漫游，临时通过微信"中国移动国际漫游"在线客服开通也要等生效。港币可在 First 兑换店换现金，或用 Visa 信用卡在交通银行取现，当地大多支持支付宝/微信支付，交通用支付宝坐地铁巴士。

## 香港个人账户注册 Stripe
- 链接：http://mp.weixin.qq.com/s?__biz=MzkzNzYzNzE3Mg%3D%3D&mid=2247484110&idx=1&sn=4fe5ad8ca9b23269a1a67a74512e5417&chksm=c28d2695f5faaf8367226e5c0236148ef1b40983feb16352a3317fb4594a4960109339f494ae#rd
- 详情：注册地址 dashboard.stripe.com/register，作者用 Google 账号注册、国家选香港，全名填昵称、商家名称先写网站名（可后改）。选积分购买+订阅后进入沙盒模式，点"切换到真实模式"进入认证。一、验证业务：商户类型选香港/个人；姓名邮件出生日期如实填；家庭住址可在某宝购真实住址（避免收账单风险）；电话切 +86 用大陆号；香港身份证用护照；行业选软件、公司网站填可访问网址；公开详情里账单描述符（用户卡账单显示文字）填网站名。二、添加银行账号：用众安 ZA BANK，账号在 APP"我的存款"里查"户口号码"（非卡号），提现选手动。三、添加通行密钥（WebAuthn），设 6 位 PIN 并保存备份代码。四、在设置→商家→账户状态里做身份认证，需拍摄护照上传，且必须用香港节点否则提示"不支持的国家"。审核期间也能收款。

## Stripe 产品配置
- 链接：http://mp.weixin.qq.com/s?__biz=MzkzNzYzNzE3Mg%3D%3D&mid=2247484124&idx=1&sn=f410f74c2e97737a2793fceb2ba34a49&chksm=c28d2687f5faaf917a228476545df50c99221b1e33a9ea25370ab857ed7f1b7703a17974b80e#rd
- 详情：配置三件事——私钥、Webhook、产品创建。①在左下角"开发人员"里复制 API 私钥（Secret Key）配置到项目环境变量。②Webhook：添加端点，筛选监听事件 invoice.paid、checkout.session.completed、customer.subscription.created/updated/deleted，填 Webhook URL 与名称，创建后复制 Webhook 签名密钥备用。③产品目录里创建产品：填名称，选订阅（按月/按年）或一次性收费，注意选对收费币种，创建后复制价格 ID（Price ID）到环境变量。本地测试用 Stripe CLI 做本地转发；沙盒环境可用测试卡：4242 4242 4242 4242 成功、4000 0000 0000 3220 需 3D 安全认证、4000 0000 0000 9995 资金不足失败（文档 docs.stripe.com/testing）。核心是正确配置密钥、事件和价格 ID，才能打通支付与订阅回调。

## Stripe 注册到提现全流程

- 详情：完整链路四步——①先办港卡（见香港办卡流程）；②注册 Stripe（香港个人账号，详见注册文）；③配置 Stripe 产品与 Webhook；④提现。收款满一周后即可在"余额"页面点"提现"，弹窗确认金额即可。提现不会立即到账，在"交易→提现"可查申请记录；作者实例约 2 天多到账成功（资金到绑定港卡，如众安 ZA BANK）。要点：提现周期约 T+7，到账再等 1-3 天；提现方式选手动可自主控制节奏；绑定港卡后整个收款→结算→提现闭环跑通。整体流程依赖前述港卡与 Stripe 注册配置三篇前置步骤。

## stripe 自动设置优惠
- 链接：http://mp.weixin.qq.com/s?__biz=MzkzNzYzNzE3Mg%3D%3D&mid=2247484292&idx=1&sn=1969b605a8b0bd47262099359f65b911&chksm=c28d27dff5faaec9b5f0500e374420c45f50b8e863e81cd99fa4bb5fab4782dcc999d0099b4b#rd
- 详情：实现用户购买时自动套用优惠码、无需手动填写。步骤：①在 Stripe 后台新增优惠券（Coupon），填优惠名称、折扣（百分比或固定金额）、持续次数（duration）。②在支付代码的 checkout 逻辑里加上 discounts 字段并填入该优惠码 ID，自动应用。关键坑：必须去掉 allow_promotion_codes（若该参数为 true 允许用户手动填码，会与自动 discount 冲突导致请求报错）；若要让用户手动输码才设 allow_promotion_codes=true。官方文档 docs.stripe.com/payments/checkout/discounts。适用场景：拉新自动首单折扣、活动固定优惠。注意折扣次数设置，避免被无限复用薅羊毛。

## 无需登录支付也能收款

- 详情：分享小红书虚拟商品收款案例——一款 4.99 美元产品卖出近一万单，靠小红书笔记引流。流程：用户在小红书店铺下单付款 → 自动发货一个带 code 的链接 → 用 code 到网站分配生成次数（如视频生成额度）。网站极简，无需繁琐登录注册。思路要点：走"虚拟商品"形式，需在小红书开店铺（无账号门槛但需交押金），用平台担保交易规避自己搭支付。适合轻量工具/一次性虚拟交付，把收款交给小红书、自己只管发货与额度分配。注意：这是国内平台模式，出海站点仍应以 Stripe/Paypal 等为主；该案例价值在于"免登录+code 分发"的极简转化链路设计。

## 防止用户薅羊毛
- 链接：http://mp.weixin.qq.com/s?__biz=MzkzNzYzNzE3Mg%3D%3D&mid=2247484728&idx=1&sn=17c5b6b9321fa98b8c0c3bd516cbc197&chksm=c28d2163f5faa8755a368114b76f1295d2e8606552809c55b8da8283ac28b13d43a4a8978689#rd
- 详情：作者网站原限制仅 Google 登录、注销重注册不送积分，以为能防无限邮箱薅羊毛，结果发现有用户用几十个 Google 账号换号薅免费试用，累计被薅三四十刀。对策：①加积分赠送限制——同一 IP、短时间内多次注册，赠送积分大幅减少，使其无法生成视频；②发现多次薅羊毛用户后限制其生成能力，减少损失。后续计划：发达地区多赠积分、常薅羊毛地区少赠，总赠送量不变，平衡付费率与防薅。要点：仅靠"登录方式限制"不够，需结合 IP、设备、注册频次等维度做风控；积分/试用额度要有反刷机制，避免被多账号撸穿。

## stripe 高质量外链
- 链接：http://mp.weixin.qq.com/s?__biz=MzkzNzYzNzE3Mg%3D%3D&mid=2247484763&idx=1&sn=909a30c61cd32c5b0e76076a4c19fbdd&chksm=c28d2100f5faa816108a6add1c090993a097a6dc0b31c6d01c1858f75a7943e91f16bbf5871e#rd
- 详情：从 Stripe 获取一条 DR 94 的 dofollow 高质量外链。做法：在 Stripe 搜索 "climate" 找到气候保护入口，需捐赠一小部分给气候组织（最低可设支付金额的 0.1%，或固定每月扣 1 港币）。设置后可自定义网页 icon、名称、跳转链接等信息，完成后即获得一个 dofollow 外链。建议把该链接放到网页底部，方便 Google 抓取。要点：这是用小额捐赠换高权重（Stripe 域名 DR 94）反向链接的 SEO 技巧，成本极低（每月 1 港币起），适合想快速提升新站外链权重的出海站点。注意捐赠会持续扣费，按需设最低额。

## stripe 收款设置，避免不必要的损耗
- 链接：http://mp.weixin.qq.com/s?__biz=MzkzNzYzNzE3Mg%3D%3D&mid=2247484803&idx=1&sn=47caf3cb1e5ccd9ad98f203a390c9a59&chksm=c28d21d8f5faa8ce9b1623e423bfabcd3ef617ce8e38b211004f1644d7889a1274b375aaedec#rd
- 详情：作者发现 Stripe 扣了一笔"货币兑换费"——因用港币收款但用户付美元，费率 2%。优化方法：右上角"设置→商家→银行账号与货币"，添加结算货币（选美元收款），输入统一银行卡号后添加，并把新方式设为默认。改后提现费仅 1%，比货币兑换的 2% 省 1%。额外收益：此前买美元产品也走该账号产生换汇费，现直接美元结算，相当于少了两次换汇磨损（收、付各一次）。要点：跨境收款币种尽量与用户支付币种一致（美元对美元），避免 Stripe 2% 货币兑换损耗；结算货币可多币种设置，按主要客源选默认。省下的 1% 对薄利产品很关键。

## 定价时需要考虑 stripe 的手续费
- 链接：http://mp.weixin.qq.com/s?__biz=MzkzNzYzNzE3Mg%3D%3D&mid=2247484839&idx=1&sn=2c5cc3b2d5bcdffb2deb9bca27a98f70&chksm=c28d21fcf5faa8eae03ef618b8585f0949e49eb96c198ee3e2058cadba5a82806332a26b6c77#rd
- 详情：算 Stripe 账单发现手续费对低价产品吞噬严重。Stripe 标准费率约 2.9% + $0.30/笔，重点在 $0.30 是固定费：卖 $4.99 手续费近 10%，卖 $9 也要 7%+，到 $19/$29 才回落到 5% 左右；叠加国际卡、换汇后实际成本更高。建议：①低价档务必考虑高手续费率折损；②按"最坏手续费"倒推定价（即定价要覆盖 2.9%+$0.30+换汇）。作者账单中 79.8 那笔是未改美元结算前的（含 2% 货币兑换费），改美元结算后只剩 1% 提现费（详见上篇"避免损耗"）。要点：定价不能只看毛利，要把固定 $0.30 和百分比一起算进去，单价越低费率占比越高。

## 定价小技巧
- 链接：http://mp.weixin.qq.com/s?__biz=MzkzNzYzNzE3Mg%3D%3D&mid=2247484885&idx=1&sn=7113cf8262f5007011829fbe005f6004&chksm=c28d218ef5faa89866ec20ac5c19333c974afda6e89b1c25f9a5f7459871d1a31766cd22f57c#rd
- 详情：从小红书电商偷来的定价策略——先定偏高"原价"，再用优惠券/限时折扣把实际成交价拉到想卖的价位，而非直接标最低价。原因：①直接低价后想涨价很难（老用户心理落差）；②做促销没空间；③联盟/分销佣金分不出；④节日活动不好玩。反过来：定高官方价 + 大折扣 = 实际合理低价，好处是后续涨价有空间、优惠可逐步收紧、联盟返佣好算、用户还觉得"现在买很划算"。要点：不要用最低价限定死，用"原价+折扣"留出操作空间，配合 Stripe 优惠券（见自动设置优惠篇）实施。该策略与手续费倒推定价互补——在覆盖成本基础上保留营销弹性。

## 雷达设置，防止 stripe 封号
- 链接：http://mp.weixin.qq.com/s?__biz=MzkzNzYzNzE3Mg%3D%3D&mid=2247484991&idx=1&sn=ea79b2a209df88509b7df6b4a348e2a5&chksm=c28d2264f5faab72472c07a9e8d88915638b317dc15a45b41591a33df04e8c1c59643eaa6596#rd
- 详情：有朋友 Stripe 账号被坏人盗刷利用遭封号，作者提醒务必开 Radar。Radar 检测异常支付：部分用户不用积分、用很多卡试买，大概率是盗刷；用户找回卡发起争议（dispute），不仅要退款还要付 $20 争议费，争议率/异常支付过高会被封号。设置：①设置里找 Radar，升级到"Radar 风控团队版"；②产品→Payments→Radar→规则 添加规则（引用哥飞群友规则，含 3DS、block、manual review 三类：如菲律宾(PH)/新加坡(SG)高风险卡、risk_score>30/40、refund/dispute 次数、同卡同 IP 周频次、同姓名绑多卡等）；③分别在"请求 3DS 验证/阻止/审查"挂上对应规则；④风险控制里"阻止更多欺诈"，风险分>50 全阻止。要点：必开 Radar 团队版，按地区与风险分设拦截阈值，防盗刷与封号。
