## 完整开发流程（从 0 到上线到变现）

### 1. 找需求
- Google Trends + Similarweb + Semrush 找低竞争高搜索量关键词
- 用搜索语法（site:/inurl:/allintitle:）分析竞品收录情况和词难度
- 词根扩词法：一个词根用 AI 扩展出几十个长尾词
- KGR/EKGR/KDROI 公式评估一个词是否值得做

### 2. 做原型
- 用 v0/Bolt 生成 UI，和 ChatGPT 头脑风暴确定 MVP
- Starter Kit（如 shadcn-landing-page、mksaas 模板）加速开发

### 3. 写代码
- Cursor + Claude Code，搭配 .cursorrules 让 AI 了解项目结构
- Claude Code 命令化重复操作，减少重复提示
- 注意 Next.js 漏洞防范，避免 Vercel 账单暴涨

### 4. 部署
- GitHub 提交 → Vercel 自动部署 → 绑定域名（Namecheap/Spaceship）
- Cloudflare 做 CDN 和安全防护
- Cloudflare R2 做免费存储

### 5. 收录
- GSC 提交收录，手动请求索引加快速度
- GA 分析数据，Clarity 看热力图
- 多平台收录（Bing、Yandex 等）

### 6. SEO 核心：低 KD 多内页
- 不做大词争前三，铺大量长尾关键词内页
- 基于 GSC 出词数据反向新增内页
- 图片 SEO：高清大图 + alt 文本 + 语义化文件名
- 多语言适配，布局 AI 搜索（GEO）

### 7. 推广
- Product Hunt 发布
- Reddit 营销（养号攒 karma，注意社区规则）
- 推特起号
- GPTs 给网站引流
- 分享裂变

### 8. 外链建设
- 竞品外链分析法
- 上架 Chrome 插件（DR99 高质量外链）
- Hacker News / 20 个免费外链平台提交
- 好外链 6 标准

### 9. 变现
- AdSense 广告
- Stripe/Creem 订阅（定价不低于 $19）
- 涨价策略、AB 测试、价格锚点
- 海外挣美刀内地花（Wechat Pay HK / 水星银行）

## 核心方法论速览

- **低 KD 多内页打法**：8 条外链拿下 41K 月访问量，核心是不争大词、铺大量长尾内页
- **搜索即需求**：用 Google 搜索语法把搜索行为转化为需求信号
- **定价锚点**：单次最贵、月付居中、年付最优惠，提升客单价
- **损失厌恶**：在网站设计上运用心理学（限时、限时限量、试用期等）
- **种子用户打法**：找到第一批种子用户，通过分享裂变放大
