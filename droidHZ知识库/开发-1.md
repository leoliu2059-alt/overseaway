## 注意后端渲染
- 链接：http://mp.weixin.qq.com/s?__biz=MzkzNzYzNzE3Mg%3D%3D&mid=2247483931&idx=1&sn=f36a960f5c18f495f9a1927b80e58bb6&chksm=c28d2640f5faaf56470efd7972a3c14953c899e7d4088296a079f11b81def8766a04fd5d6df2#rd
- 详情：文章讲 SEO 中"后端渲染（SSR）"的必要性。新网站即使做了 on-page SEO，若用纯前端 JS 渲染，Google 爬虫需额外算力触发渲染，新站往往排不上，导致 SEO 努力白费。后端渲染能直接返回完整 HTML，爬虫可直接抓取内容。检测方法：安装 AITDK 插件，用其 Server Side Rendering Check 功能扫描页面——全绿表示后端渲染，红色代表前端渲染。文中以已破百万浏览的 nanobanana.ai 为正面案例（全绿），以作者自己的 makememe 为反面教材（纯前端渲染）。结论：新站务必老老实实做后端渲染，细节决定 SEO 成败。

## 用嘴编程一些技巧
- 链接：http://mp.weixin.qq.com/s?__biz=MzkzNzYzNzE3Mg%3D%3D&mid=2247484426&idx=1&sn=14637712744766440d19bee63a8f39e9&chksm=c28d2051f5faa9471780a49d7616849cd0b6435014abbdb35eb2ea9e10988e7aa30d82fd765f#rd
- 详情：总结用 AI 编程（"用嘴编程"）降低"抽卡"概率的提示词技巧。核心：1）无歧义——任何人都只有一种理解，避免"高端大气上档次"这类主观词（除非你想让 AI 抽卡发挥）；2）强调实现细节并提供文档——调用什么 API 就给对应官方文档与示例代码，清楚描述功能，可附效果截图；3）一次别做太多事——AI 有上下文限制，任务过多会放大偏差导致代码不可用；4）颗粒度对齐——让 AI 写代码前先复述一遍需求确认理解一致，再动手，可显著降低返工。本质是"把需求讲清楚"。

## 付费用户追踪
- 链接：http://mp.weixin.qq.com/s?__biz=MzkzNzYzNzE3Mg%3D%3D&mid=2247484449&idx=1&sn=d0556297d209dded1af72d4d14ae6919&chksm=c28d207af5faa96c5fa82cb53a408ea963b1ca825f7f94c9ba517fef660932c58d20581f7c66#rd
- 详情：讲如何追踪付费用户来源以便归因、发现高变现渠道。方法：通过 UTM 参数（utm_source、utm_medium、utm_campaign、utm_content、utm_term）或 ref 参数识别来源，先把数据存到 localStorage，用户登录后同步写入数据库的 user 表 source 字段。作者用 Claude Code 一句话实现："检测用户来源（utm 和 ref 等参数），先存 localStorage，登录后在数据库新增 source 字段存来源"。之后让 AI 加个面板，过滤付费用户查看来源做进一步分析。本质是来源参数 + localStorage + 数据库字段的轻量归因链路。

## Google Analysis 事件上报
- 链接：http://mp.weixin.qq.com/s?__biz=MzkzNzYzNzE3Mg%3D%3D&mid=2247484483&idx=1&sn=b87ae2ed921724fbbca672989175f10c&chksm=c28d2018f5faa90e11a06f216cfef43a7aab1d9ccdad64a8d971a4c6938bce33f2cdaa4460dd#rd
- 详情：讲 GA4（Google Analytics）自定义事件上报，用于分析产品互动与留存。做法是在前端调用 gtag 函数上报事件，数据可在 GA 后台"报告 → 用户互动度和留存率 → 事件"查看。代码示例：gtag('event', '<event_name>', { value: 99.99, currency: 'USD', transaction_id: 'T12345', items: [...], custom_param: 'any_value', another_param: 123 })；其中 value/currency/transaction_id/items 为 GA4 内置推荐参数，其余为任意自定义键值对。官方文档：https://support.google.com/analytics/answer/9234069。核心是前端埋点传参，便于后续按事件分析转化。
