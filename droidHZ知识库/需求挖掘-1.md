- 详情：本文系统讲解 Google 搜索语法用于分析网站与竞品。核心语法：`site:wan2-2.ai` 指定域名搜索，可看自己的网站页面是否被 GSC 收录（如 wan2-2.ai 收录4个页面）；`inurl:wan2.2` 指 URL 含某关键词（或关系），`allinurl` 为且关系；`intitle:wan2.2` 与 `allintitle` 针对标题，可快速找 title 相似的竞站，如 `allintitle:wan video generator` 看竞品数量评估词难度；`intext`/`allintext` 针对正文。方法论：以「搜索即需求」为原则，通过标题/URL/正文关键词组合定位竞品与需求强度，是后续词找词、站找站的基础工具。

- 详情：本文介绍用 web.archive.org（Wayback Machine）查看网站历史快照，洞察成功网站的「来时路」。操作步骤：输入目标网址即可看到快照信息；顶部年份柱状图显示变化频次，选某年打开变化日历，点击时间点查看当时网站样貌；可切换 Collections 查看不同存档集合；点 Changes 看变化日历并选两个时间点对比差异；查看 Summary 与饼图形式的 sitemap，掌握全部 URL。关键价值：通过观察别人上站节奏、各内页上线时间，学习其产品演进路径，反推自己的建站策略。

## 找词找站找需求

- 详情：本文在「词找词」基础上补充「词找站、站找词、站找站」三类方法。词找站：用需求词直接 Google 搜索找相关网站，或用 query.domains 查关键词相关域名站。站找词（从网站倒推需求词）：①GSC 看自己站相关搜索词；②SimilarWeb 输入网站看关键词；③Semrush 看网站关键词；④ai tdk 看 top 关键词；⑤Google Trends Everywhere 插件在搜索结果页直接看网站 top 搜索词。站找站（找同类竞品）：①SimilarWeb 的「相似网站」；②pubspy.io 插件按同一 AdSense Publisher ID 反查同一人做的所有站。形成「词↔站」双向闭环挖掘。

- 详情：本文讲用 SimilarWeb 的「着陆页（Landing Page）」功能找词。以 crazygames.com 为例：进入关键词研究 > 着陆页，输入目标网站；在「点击量变化」过滤项选「新点击量（New traffic）」，即可筛出近期流量上涨的页面（绝大多数是新上页面）；右侧显示热搜关键词，再用 Google Trends 核对这些词的增长趋势，判断是否为新需求/上升需求。方法论：盯竞品新页面 + 热搜词 → Google Trends 验证，可迁移到任何品类批量找词。

## 找到一个人做的所有网站

- 详情：本文推荐浏览器插件 PubSpy.io，用于反查某个人/公司做的所有网站。原理：同一 AdSense 账户下所有网站的 Publisher ID 相同（账户级唯一标识），故可用 ID 反查同主全部站点。操作：在目标网站点插件即可出结果。示例：截流站 raphaelai.org 经此插件发现其做了不少「李鬼」站且各有流量。底部三个按钮：①一键打开所有网站；②导出为 Excel；③通过 traffic.cv 查看网站变化趋势。用途：摸清明竞品的产品矩阵与流量走势。

## 如何分析榜单和竞品
- 链接：http://mp.weixin.qq.com/s?__biz=MzkzNzYzNzE3Mg%3D%3D&mid=2247484261&idx=1&sn=a385552c14dc5a25b26c5a12a449db10&chksm=c28d273ef5faae285079336ac757bb0d6160494a5bcce9b25a7aca4c1e026cc109bd243fec46#rd
- 详情：本文基于刘小排方法，用「信息论—信噪比（有用信息/干扰信息）」框架分析榜单与竞品。原则：能力之外不动心，能力之内学扎实（如决定做视频就只看视频）。操作步骤：①流量来源用 AITDK、SEMRUSH 看来源国家（专注高付费国家、付费流量）；②SEO 审查用 claude Agent 跑「分析 xxx.com 全面 SEO 情况并输出报告」，AITDK 看页面级 SEO 做法；③技术实现问 AI + Wappalyzer 看技术栈；④产品体验靠见多识广。榜单源用 Toolify（theresanaiforthat），其 API `https://www.toolify.ai/self-api/v1/top/month-top?page=1&per_page=200&direction=desc&order_by=growth` 可拉数据，把数据丢给 AI 筛选重点网站；重点看「异常值」（异常=信息量大），用 AI 工具提高信噪比。

- 详情：本文在「搜索语法」基础上，叠加 Google 工具中的「时间限制」找新需求。要点：时间过滤的日期指 Google 认为内容首次发现/最近更新的时间（可近似理解为收录时间，并非发布时间）。组合用法：①用 `allintitle:词根` 配时间过滤，发现「用该词根新上线的页面」（新竞品/新需求）；②用 `site:关注的网站` 配时间过滤，发现某站「新上页面」。方法论：把词根+时间窗口+搜索语法结合，持续监控新出现的页面，第一时间捕捉新兴需求与竞品动向。

## 出站流量找到受关注的产品

- 详情：本文讲通过「出站流量」发现受关注的产品与导流效果。方法：对 toolify、traffic.cv 这类站点用 SimilarWeb 看出站流量（outgoing/referral），能看到哪些目标网站受欢迎、导流效果如何；也可通过 YouTube、Reddit 找备受关注的网站。延伸价值：发外链时，可查竞品的哪个外链导流多，就去发同样的外链，借力已验证的高转化渠道。本质是用流量去向反推「用户当前在关注什么」，比直接搜词更贴近真实行为。

- 详情：本文介绍群友开发的「基于评分找需求」工具：chrome-extension-viewer.vercel.app。核心思路：「收集抱怨找需求」——找差评，尤其「高下载量+差评多」的产品，说明需求大但现有产品未满足或存在痛点，即机会点。两个使用场景：①筛选评分低、评分人数多的插件，找蓝海机会；②筛选下载量高的插件，开眼界洞察「原来用户还有这种需求」。方法论：把 Chrome 应用商店的差评当作需求矿，用评分×下载量矩阵定位可切入的细分痛点。

## HeyGen 找需求示例分享
- 链接：http://mp.weixin.qq.com/s?__biz=MzkzNzYzNzE3Mg%3D%3D&mid=2247484495&idx=1&sn=adeffd9c8955a807572e8fa15e5240a6&chksm=c28d2014f5faa902515d6aaefde82dd11661f8804542fbaff3e497a4e34a7de1624d4d62a5cb#rd
- 详情：本文以 HeyGen（视频多语种翻译配音）为例，讲「先找用户再做产品」。HeyGen 2022-07-29 起 7 个月从 0 做到 100 万美元 ARR，关键在于先在 Fiverr（fiverr.com）搜索 spokesperson 发现有 1811 项任务，说明有人愿付费；于是在 Fiverr 上发布「按需多语言视频服务」，不透露头像是 AI 生成，成本仅 10%、交付 10 分钟（vs 几天），凭低价+快速脱颖而出；后续披露 AI 生成用户也不在意，只要效果达标。方法论：到 Fiverr、Upwork、咸鱼等远程/任务平台先找真实付费用户与任务量，再反向做产品，需求已被市场验证。

## 卖空气验证需求
- 链接：http://mp.weixin.qq.com/s?__biz=MzkzNzYzNzE3Mg%3D%3D&mid=2247484519&idx=1&sn=069312d4f7c63344e64047457955d428&chksm=c28d203cf5faa92aa4ffe8f926e5af73c2244307cef26acd9e4305a3ce3b234bd7ed0dac7549#rd
- 详情：本文讲「卖空气（预售）」验证需求法——产品未成型就定价预售，看多少人愿提前付费。案例：Pieter Levels 写《MAKE》时只写部分内容+大纲，搭简单落地页放「正在写，可买预售版」，预售期即赚大笔收入并验证市场，出版时已稳定。可落地步骤：①在朋友圈/社群宣传付费产品并定真实价格（别太便宜以免是人情单），看愿付费人数；②上线营销 Landing Page：写解决什么问题+3个卖点→用 AI 生成页面→接 Stripe 支付→买 Google 关键词广告，盯转化率。小红书上也有人用预售集单后再生产。核心：别等产品做完再验证，敢「卖空气」、早验证、无效则果断止损，时间最值钱。
